## 🏗️ Engineering Mindset

> I build backend systems and AI automation pipelines with the same discipline — reliability, traceability, and graceful failure handling are requirements, not afterthoughts.

<table>
<tr>
<td valign="top" width="50%">

**Backend & System Principles**

- API contracts are the product — version, document, never break silently
- Every production query has an `EXPLAIN ANALYZE` behind it
- Services will fail — design for graceful degradation and recovery
- Distributed state is hard — Redis is a cache, not a source of truth
- Schema migrations are code — reviewed, versioned, tested before deploy
- Logging + metrics + health checks are non-negotiable in production

</td>
<td valign="top" width="50%">

**AI Automation Principles**

- LLMs are non-deterministic — always validate and sanitise output
- Prompt engineering is engineering — version and test prompts like code
- n8n workflows need error paths as much as happy paths
- AI pipelines must be observable — log every step, token, and failure
- Separate orchestration from AI calls — swap models without rewriting flows
- Cost awareness matters — token budgets are as real as compute budgets

</td>
</tr>
</table>
